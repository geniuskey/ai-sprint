# AI Sprint 설계 결정

## 공식 사실과 준비 가설

2026-10-13에 아래 원문을 확인했다.

- [대회 공식 홈페이지](https://skhynix-hackathon.com/ai-2026): 1차 예선은 10월 17~18일 중 하루, 온라인 AI 기초 지식·활용 역량 평가.
- [SK하이닉스 발표](https://talent.skhynix.com/hub/ko/company/story/237): AI 리터러시, 문제 정의, AI 활용, 결과 검증을 평가.

사용자 요구사항의 10월 18일 14시와 15시, 20문항/30분과 16문항/90분은 개인 준비 일정으로 사용한다. 공개 원문으로 이 시간·문항 수·객관식 형식을 확인하지 못했다. A를 기초지식형, B를 사례형으로 만드는 것은 학습을 위한 설계 가설이다. 실제 출제 범위·도구 사용 허용 여부·합격 확률을 주장하지 않는다.

## 우선순위

각 개념의 `priorityReason`에 판단 근거를 기록한다. P1은 공개 평가 방향과 밀접하고, 다른 개념의 선수 지식이거나 실전 오류를 크게 줄이는 내용이다. 문제 정의, 평가 지표, 데이터 누출, 검증, RAG와 Agent의 경계 등이 여기에 속한다. P2는 적용 원리를 설명하는 주요 세부 기술이다. P3은 제한된 기간에서 상대적으로 후순위인 최신 구조와 구현 세부다. 이는 출제 확률이 아니다.

기본 경로: 핵심 기초 → 데이터/평가 → 프롬프트/검증 → RAG → Agent/도구 안전 → 사례 판단 → 제한 시간 모의시험. 오답과 복습 예정 개념을 앞에 노출한다. 일반 학습 모드는 시험일까지 남은 시간에 따른 복습 제한을 해제한다.

## 데이터와 저장

콘텐츠는 `content/*.json`, 문항은 각 파일의 독립적인 `questions` 배열, 사용자 진도는 `data/ai-sprint.sqlite`에 분리된다. 개념과 문항은 안정적인 slug ID로 연결한다. 콘텐츠 수정은 사용자 DB를 초기화하지 않는다. 이미 시작한 시험은 문항 스냅샷을 저장해 콘텐츠 변경 후에도 채점 기준을 보존한다.

SQLite 테이블은 `progress`, `attempts`, `exams`, `bookmarks`, `settings`, `events`다. 읽기는 숙련도를 올리지 않는다. 퀴즈·시험 정답은 숙련도 +20, 오답은 -30, 범위는 0~100이다. 이는 이해도의 절대 측정치가 아니라 앱 안의 설명 가능한 연습 지표다. 반복해서 외운 같은 문항으로 높은 점수를 얻을 수 있으므로 사례 판단과 함께 해석한다.

간격 반복:

- 모름 또는 오답: 10분 뒤.
- 헷갈림: 1시간 뒤.
- 알고 있음/정답: 연속 성공에 따라 1, 2, 4, 최대 7일.
- 완벽히 이해: 3, 6, 12, 최대 14일.
- 시험 5일 이내: 최대 12시간 또는 남은 시간의 1/3로 제한. 최소 10분.
- 주관적 이해도는 다음 복습을 조정하지만 객관적 숙련도를 올리지 않는다.

쓰기 이벤트 ID로 중복 저장을 방지하고 시험 채점은 트랜잭션으로 한 번만 반영한다. 서버 시각으로 시험 만료를 검사한다. 새로고침은 종료 시각을 연장하지 않는다. 백업에는 학습 기록과 시험 스냅샷을 포함한다. 복원 입력을 검증한 뒤 기존 데이터를 자동 백업하고 트랜잭션으로 교체한다.

## 화면과 학습 루프

모바일 하단의 홈/학습/복습/시험/통계를 중심으로 이동한다. 개념 화면은 핵심 요약, 먼저 떠올리기, 쉬운 설명, 펼치는 실무 사례/기술 설명, 선택지별 해설 순이다. 10분 학습은 짧은 묶음이며, 자기평가 카드와 퀴즈를 구분한다. 비교 화면에서는 임의의 두 개념을 선택한다. 실전 시나리오는 제약조건과 대안을 함께 검토한다.

## 운영과 접근 통제

React + TypeScript + Vite, Express, Node 내장 SQLite로 서버 프로세스 하나를 사용한다. 현재 Mac의 Node 26 환경을 사용하며 Node 24 이상이 필요하다. 서버는 127.0.0.1:8787에만 바인딩한다. Tailscale Serve는 별도 HTTPS 8788 포트에서 이를 프록시한다. 기존 Serve 경로와 포트는 보존한다. Funnel과 공용 호스팅은 사용하지 않는다.

사용자 요청에 따라 앱 접속 코드와 세션 인증을 제거했다. Tailscale tailnet 정책으로 접근을 통제하며 앱은 loopback에만 바인딩한다. 쓰기 API의 동일 출처 검사는 유지한다. macOS LaunchAgent로 로그인 시 자동 실행, 비정상 종료 시 재시작, 매일 백업을 구성한다. FileVault 잠금 해제 전·사용자 로그인 전 실행은 LaunchAgent의 보장 범위 밖이다.
