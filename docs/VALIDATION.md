# 구현 및 검증 결과

검증일: 2026-10-14 (Asia/Seoul)

## 구현 범위

모바일 우선 React/TypeScript 학습 화면, 홈의 10분 학습과 우선순위 추천, 검색·필터, 단계별 개념 설명, 회상 및 응용 퀴즈, 주관적 이해도 카드, 간격 반복, 북마크, 비교 프리셋, 시나리오 판단, 최종 암기 노트, 통계, 다크 모드를 구현했다. SQLite 서버에 답변과 숙련도·복습 시점·설정·시험을 저장한다. 화면에 돌아오면 서버 진도를 다시 읽는다.

모의시험 A는 20문항/30분, B는 16문항/90분이다. 정답은 시험 화면에서 제출 후 표시하며, 문제 이동·답변 변경·북마크·서버 자동 저장·시간 만료·결과 및 오답 해설·재시험을 제공한다. 공개 자료에서 확인되지 않은 실제 형식 대신 준비용 가설임을 표시한다.

실전 시나리오는 8개다. 각 개념에는 회상형 1개와 응용형 1개 이상, 모든 선택지의 해설과 출처를 포함한다. 자동 검사는 필수 필드, 고유 ID·제목·질문, 개념/문항/선수 지식/시나리오 링크, 선수 지식 순환, 4개 고유 선택지, 정답 인덱스, 설명 필드, 정답 위치의 전체 및 유형별 분포를 검사했다. 최종 오류 0개이며 정답 위치 분포는 52/54/53/51이다.

작성자는 공식 문서와 논문에 핵심 원리를 대조했다. 별도 AI 검토에서 105개 개념의 주요 설명, 210개 문항·해설, 8개 시나리오를 검토하고 다음을 수정했다.

1. `e-workflow-recall`: 분기 없는 워크플로도 가능하여 기존 오답이 유효했다. 질문과 선택지를 명확한 정의 판단으로 다시 작성했다.
2. `neural-network`: 편향이 있는 층의 합성은 아핀 변환이며 편향이 없으면 선형 변환이라고 본문과 해설을 맞췄다.
3. `d-embedding-model`: 서로 다른 모델은 항상 호환 불가라는 표현을, 같은 차원만으로 호환성이 보장되지 않는다는 표현으로 수정했다. 공동 학습된 비대칭 인코더가 호환 공간을 쓸 수 있다.
4. `s-csv-report`: 제외 규칙이 겹치는 행의 중복 집계를 피하도록 행 수 검증식을 수정했다.

출처별 검토 범위는 [기초 영역 출처 기록](sources-foundations.md), [실전 영역 출처 기록](sources-practice.md)에 있다. 구조 검사와 AI 자체·별도 검토가 전문가 독립 감수, 모든 참조 문서의 전수 대조, 실제 기출 검증 또는 오류 부재 보장을 의미하지는 않는다.

## 자동 검사

`npm run check` 통과:

- 콘텐츠 검증
- TypeScript 타입 검사
- ESLint
- 서버 테스트 7개
- 프로덕션 빌드

`npm run test:e2e` 통과: 실제 Chrome 브라우저 테스트 4개.

서버 테스트는 로그인 없는 직접 접근과 동일 출처 제한, 잘못된 입력 거절, 중복 답변 방지, 복습 알고리즘, 독립 요청의 진도 동기화, SQLite 재연결, 시험 생성과 영역 분배, 답변 변경·임시 저장·복구, 제출 전 답/해설 제거, 단일 채점, 서버 시간 만료, 백업·복원과 잘못된 백업의 원자적 거절을 확인했다.

브라우저 테스트는 412×915 및 360×800 화면의 가로 넘침, 학습·퀴즈·북마크, 독립 데스크톱 브라우저에 진도 반영, 회상 카드, 비교·시나리오, 시험 답변 후 새로고침, 결과 화면, 다크 모드·목표·일반 모드 저장, 실제 백업 다운로드와 파일 업로드 복원을 확인했다. 테스트는 별도 임시 DB를 사용해 운영 학습 기록을 오염시키지 않았다.

## 배포 확인

- 개인 tailnet HTTPS: https://macstudio.nutria-sole.ts.net:8788/
- 내부 서버: `127.0.0.1:8787`
- Tailscale Serve의 기존 모든 설정 키와 값을 배포 전후 비교해 보존됨을 확인했다.
- 새 8788 포트는 HTTPS이며 Funnel을 사용하지 않는다.
- Mac Chrome에서 실제 HTTPS 주소에 접속하고 105개 개념/210문항을 읽었다. 브라우저 오류 0건. 접속 코드 제거 후 새 브라우저에서도 로그인 없이 학습 화면이 열리는지 확인했다.
- LaunchAgent `com.geniuskey.ai-sprint`가 실행 중이다. SIGTERM으로 이 서비스만 종료한 뒤 다른 PID로 자동 재시작하고 HTTPS health가 정상임을 확인했다.
- `com.geniuskey.ai-sprint.backup` 설치 후 첫 백업이 생성됐다. 매일 03:15 실행, 최근 30개 정기 백업 유지.
- 서버 및 백업 오류 로그는 검증 시 비어 있었다.

## 확인 한계와 남은 사항

Galaxy 실제 기기에서 URL을 열었는지는 사용자 확인이 필요하다. Chrome의 모바일 크기 테스트와 Mac의 Tailscale HTTPS 확인을 실기기 확인으로 간주하지 않는다.

실제 재부팅은 기존 서비스에 영향을 주므로 수행하지 않았다. LaunchAgent의 RunAtLoad·KeepAlive 설정과 종료 후 재시작은 확인했다. 재부팅 후 **사용자 로그인**이 필요하며, FileVault 잠금 해제 또는 로그인 전 시스템 서비스 실행을 보장하지 않는다. 운영 절차는 [운영 문서](OPERATIONS.md)를 따른다.

## 추천 시작 경로

홈 **오늘의 10분 학습** → 먼저 자신의 말로 설명 → 퀴즈 2문항 → 복습 카드. 이어 Precision/Recall, RAG/Fine-tuning, Agent/Workflow, Tool Calling/MCP 비교를 확인한다. 실전 시나리오에서 선택 이유와 검증 방법을 설명하고, 마지막에는 취약 개념 노트와 A/B 모의시험으로 복습한다.

## 접속 코드 제거

사용자 요청으로 앱 로그인·로그아웃·인증 API를 제거했다. 앱은 Tailscale 내부 주소에서 바로 열린다. loopback 바인딩과 쓰기 요청의 동일 출처 검사는 유지했다. 기존 코드 파일과 인증 세션만 정리하며 학습 데이터는 그대로 보존한다. 변경 후 타입·Lint·빌드·서버 7개·브라우저 4개 검사를 다시 통과했다.
